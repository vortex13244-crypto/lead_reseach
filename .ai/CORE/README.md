# CORE — Internal AI Library

Ця папка містить внутрішні правила та довідники для ШІ. Її не потрібно відкривати для старту нового проєкту.

Почніть із [START-HERE.md](../START-HERE.md). Усередині `CORE`:

- `roles/` — режими роботи ШІ;
- `standards/` — правила коду, структури та UI;
- `workflows/` — покрокові процеси;
- `checklists/` — перевірки перед релізом;
- `knowledge/` і `snippets/` — довідка та заготовки;
- `docs/`, `prompts/`, `memory/` — внутрішня документація й шаблони.
