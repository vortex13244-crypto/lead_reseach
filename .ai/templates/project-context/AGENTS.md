# Project AI Entry Point

Before changing this project, read in this order:

1. `.ai/active-context.md`
2. `.ai/PROJECT.md`
3. `.ai/architecture.md` only if the task changes structure, data, APIs, or integrations
4. `.ai/design-brief.md` only for UI work
5. The relevant workflow or checklist in the shared AI workspace

Keep changes small, follow the project's existing conventions, never expose secrets, and update `active-context.md` after meaningful work.
