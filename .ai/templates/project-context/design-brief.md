## Interaction

- Motion direction: restrained / none / Apple-inspired.
- Respect `prefers-reduced-motion`; all key actions must work without animation.
- State the required loading, empty, success, and error states.

## Accessibility

- Target: WCAG 2.1 AA minimum.
- Keyboard navigation and visible focus are required.
- Text and controls must meet contrast requirements.
