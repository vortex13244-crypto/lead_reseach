# Next.js Site Profile

Use for landing pages, company sites, portfolios, dashboards, and small web apps.

## Recommended default

- Next.js App Router + TypeScript + Tailwind CSS.
- Use server components for data work; add client components only for browser interaction.
- Use a lightweight backend/API only when a real server-side need exists.
- Start with a modular monolith rather than microservices.

## Before the first implementation

1. Copy `../../project-context/` to the product as `.ai/`.
2. Complete `PROJECT.md`, `architecture.md`, and `design-brief.md`.
3. Decide whether the visual direction is standard, custom, or Apple-inspired.
4. Define mobile, desktop, loading, empty, error, and accessibility behavior.

## Premium UI option

If the brief asks for polished, calm, tactile presentation, use [Apple Design](../../../SITES-SKILLS/APPLE-DESIGN.md). Prefer clarity, system typography, careful spacing and responsive feedback over decoration. Motion must be purposeful, interruptible where gesture-driven, and reduced-motion safe.
